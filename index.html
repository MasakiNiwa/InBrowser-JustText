InBrowser JustText

Edit text in your browser and save it, nothing more. Your files never leave the device.

  • Open — Loads a text file from your device. The encoding is detected automatically.
  • Save — Downloads the edited text as a separate file. The original file is left untouched.
  • Where the browser supports it, you can also choose a location and overwrite an existing file.
  • Find — Find and replace, with regular expressions, whole-word and case-sensitive matching.
  • Tools — Format JSON, sort lines, and more.
  • The encoding and line ending at the bottom of the screen can be changed by tapping them.
  • Add it to your home screen to launch it as an app; it works offline too.
  • On Android, share a file to this app to open it directly.
  • The row above the status bar types Tab and the punctuation that soft keyboards bury.
  • Unsaved work is kept on this device as you type, and offered back next time. Above about 4 MB it is too large to keep, and the dot beside the file name turns orange to say so.

Keyboard: Ctrl+O open / Ctrl+S save / Ctrl+F find / Ctrl+G go to line / Ctrl+Z undo / Ctrl+Shift+Z redo
