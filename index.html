InBrowser JustText

ブラウザだけでテキストをいじって保存するツールです。ファイルは端末の外に出ません。

  • 開く — 端末内のテキストファイルを読み込みます。文字コードは自動判別します。
  • 保存 — 編集後の内容を別ファイルとしてダウンロードします。元のファイルは変更しません。
  • 検索 — 検索と置換。正規表現・単語単位・大文字小文字の区別を切り替えられます。
  • ツール — JSON の整形や行の並べ替えなど。
  • ホーム画面に追加するとアプリとして起動でき、オフラインでも使えます。
  • Android の「共有」メニューからこのアプリを選ぶと、そのファイルを直接開けます。

キーボード操作: Ctrl+O 開く / Ctrl+S 保存 / Ctrl+F 検索 / Ctrl+G 行へ移動 / Ctrl+Z 戻す / Ctrl+Shift+Z 進む
