# 手で確かめること

自動の確認（`npm test` と `npm run test:browser`）では届かない範囲のための一覧です。
おもに iOS Safari と、実機でしか確かめられない挙動をまとめています。

公開先: <https://masakiniwa.github.io/InBrowser-JustText/>

## iOS Safari（iPhone / iPad）

File System Access API と共有ターゲットに対応していないため、
「保存先を選ぶ」「上書き保存」のボタンは出ません。ダウンロード保存が唯一の保存方法です。

| | 確かめること | 期待する動き |
| --- | --- | --- |
| ☐ | 起動 | 画面が崩れず、ツールバーがすべて見える |
| ☐ | 入力欄に触れる | 画面が勝手に拡大しない（文字サイズ 16px 以上） |
| ☐ | 開く | 「ファイル」アプリからテキストファイルを選べる |
| ☐ | 日本語ファイル | Shift_JIS のファイルが化けずに開ける |
| ☐ | 編集 | 日本語入力（変換中）で表示が乱れない |
| ☐ | 検索 | 強調表示が文字とずれない |
| ☐ | 保存 | ダウンロードされ、「ファイル」アプリで開ける |
| ☐ | 上書き系のボタン | 「保存先を選ぶ」「上書き保存」が **出ない** |
| ☐ | ホーム画面に追加 | アプリとして起動し、アドレスバーが出ない |
| ☐ | 機内モードで起動 | ホーム画面から起動でき、編集できる |
| ☐ | 自動保存 | 編集後にアプリを切り替えて戻ると内容が残っている |
| ☐ | 復元 | アプリを終了させて開き直すと「前回の続き」を尋ねる |
| ☐ | 表示言語 | 端末の言語（英語など）で起動する |

## Android Chrome

| | 確かめること | 期待する動き |
| --- | --- | --- |
| ☐ | ホーム画面に追加 | アプリとして起動する |
| ☐ | 共有から開く | ファイル管理アプリの「共有」に JustText が並び、選ぶと開く |
| ☐ | 保存 | ダウンロードフォルダに保存される |
| ☐ | 同名で保存 | `名前 (1).json` のように別名で保存される |
| ☐ | 機内モードで起動 | 起動して編集できる |
| ☐ | ソフトキーボード | 出したときにツールバーが隠れない |
| ☐ | 拡張子なしのファイル | 選択でき、開ける |
| ☐ | 画像を選ぶ | バイナリの警告が出る |

## パソコン（Chrome / Edge）

| | 確かめること | 期待する動き |
| --- | --- | --- |
| ☐ | 保存先を選ぶ | ダイアログが出て、選んだ場所に保存される |
| ☐ | 上書き保存 | 確認のうえ、同じファイルが書き換わる |
| ☐ | 上書きの取り消し | 確認で「いいえ」を選ぶと元のファイルが変わらない |
| ☐ | ドラッグ＆ドロップ | ファイルを落とすと開く |
| ☐ | 200% 拡大 | 画面が横に溢れない |
| ☐ | Tab キー | 選択中の場所が枠で分かる |

## 画面読み上げ

| | 確かめること | 期待する動き |

| ☐ | 通知 | 保存やエラーのメッセージが読み上げられる |
| ☐ | 検索の件数 | 件数の変化が読み上げられる |
